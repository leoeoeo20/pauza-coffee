# Пауза

Учебный сайт кофейни на HTML, CSS и JavaScript. Есть меню, рассказ о кофейне и форма расчёта стоимости напитка. Для запуска достаточно открыть index.html в браузере.

Адаптивная вёрстка: 960 и 600 пикселей. Используются Grid, Flexbox, CSS-переменные, псевдоклассы, псевдоэлементы, переходы и анимация. Форма проверяет имя и считает цену с учётом объёма и молока. Данные никуда не отправляются.
